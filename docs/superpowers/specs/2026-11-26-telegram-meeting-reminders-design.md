# Напоминания о встречах в Telegram — дизайн

Дата: 2026-11-26 · Статус: утверждён владельцем · Размер: небольшая правка

## Зачем

Клоузеры забывают встречи. Сегодняшние встречи уже есть в колокольчике CRM, но его видно
только при открытой CRM. Нужно напоминание, которое приходит на телефон.

## Решения владельца

- **Канал — Telegram**, сообщения уходят **в группу отдела продаж** (не в личные чаты).
- **Когда:** утром — сводка всех встреч на день; **за 1,5 часа** до каждой встречи — отдельное
  напоминание.
- **Всё настраивается в CRM, в разделе продаж:** токен бота, группа, Telegram-ники клоузеров.
  На сервере ничего не прописывается.

## Как работает

**Окно «Напоминания в Telegram»** — кнопка на странице «Встречи» (`/sales/meetings`), видна
только руководителю продаж (`isSalesHead` / `is_sales_head`), как «Настроить этапы».
1. **Бот.** Поле токена → при сохранении CRM проверяет его в Telegram (`getMe`) и показывает имя
   бота. Сохранённый токен целиком не показывается — только последние символы. Токен хранится
   в БД и уходит только в Telegram.
2. **Группа.** Подсказка «Добавьте бота в группу и напишите там любое сообщение». Кнопка «Найти
   группы» — CRM спрашивает Telegram (`getUpdates`), в каких группах бот видел сообщения, и
   показывает их списком; руководитель выбирает одну. «Отправить тест» — пробное сообщение в
   выбранную группу.
3. **Клоузеры.** Все сотрудники с `is_closer`, у каждого поле Telegram-ника (с `@` или без).
4. **Выключатель** — напоминания можно приостановить, настройки сохраняются.
5. **Ошибка последней отправки** (бот удалён из группы, токен отозван) — видна в окне.

**Утренняя сводка — 10:00 по Бишкеку, каждый день (вкл. выходные), только если встречи есть:**
```
📅 Встречи на сегодня, 26.11 — 3

11:00 · Айбек Т. · +996 700 111 111 · клоузер @adahan
       ул. Киевская 95 · сеттер Нурай
14:30 · …
```

**За 1,5 часа до встречи:**
```
⏰ Через 1,5 часа встреча — 11:00
Айбек Т. · +996 700 111 111
Адрес: ул. Киевская 95
Клоузер @adahan · сеттер Нурай
Открыть лида → <ссылка на /leads/{id} или /sales/meetings>
```

## Правила

- Только встречи со статусом «запланирована»; отменённые и проведённые — без напоминаний.
- Перенос встречи → напоминание по новому времени, старое не отправляется.
- Встреча назначена меньше чем за 1,5 часа → напоминание уходит сразу (если встреча ещё не началась).
- Каждое сообщение уходит один раз — и после перезапуска сервера, и при нескольких процессах
  (отметка об отправке в БД с уникальностью: встреча + вид + время встречи; сводка — по дате).
- Клоузер без ника — в сообщении просто имя, без упоминания.
- Всё время — по Бишкеку (UTC+6).

## Подходы (выбор владельца)

- **Канал.** Telegram — выбран: официально, бесплатно, без риска бана, пуш на телефон.
  WhatsApp с номера продаж — отвергнут: CRM заведёт чат с клоузером как с клиентом, бот на том же
  номере начнёт ему отвечать. Уведомления браузера — отвергнуты: на телефоне ненадёжно.
- **Куда.** Группа — выбрана владельцем: одна настройка, руководитель видит всё. Личные чаты и
  гибрид (личные + сводка в группу) — отвергнуты.
- **Где настройки.** В CRM (окно в разделе продаж) — решение владельца; не переменные окружения.

## Не-цели

Личные сообщения; кнопки в Telegram («Перенести», «Как прошла»); напоминания клиенту; приём
команд от бота кроме поиска групп.

## Что остаётся строителю (мои решения, можно менять)

- Планировщик — фоновый цикл в приложении раз в минуту, по образцу `services/whatsapp/runtime.py`.
- Хранение настроек — одна строка настроек в БД (по образцу `WhatsAppState`), ники — поле
  `telegram_username` у пользователя.
- Вызовы Telegram — `httpx` с таймаутом; Telegram-клиент подменяется в тестах фейком.
- Ссылка в напоминании — на адрес CRM из настроек сервера (базовый URL фронтенда), если он есть.
